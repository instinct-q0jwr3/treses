# 2048

El clásico puzle 2048 para jugar en el navegador: desliza las fichas y junta dos iguales para sumarlas (2 + 2 = 4, 4 + 4 = 8…) hasta llegar a 2048.

## Jugar

Abre https://instinct-q0jwr3.github.io/treses/ desde el móvil o el ordenador.

- **Móvil**: desliza en cualquier dirección sobre el tablero.
- **Ordenador**: flechas del teclado o arrastra con el ratón.
- La partida y el récord se guardan solos en el navegador.

## Reglas

- En cada deslizamiento, todas las fichas se mueven hasta el fondo en esa dirección.
- Dos fichas iguales que chocan se suman en una sola. Cada suma vale sus puntos.
- Tras cada movimiento aparece una ficha nueva (un 2 o, a veces, un 4).
- Llega a **2048** para ganar; si el tablero se llena sin movimientos posibles, la partida termina.

Sin cuentas, sin anuncios, sin conexión necesaria tras la primera carga.
