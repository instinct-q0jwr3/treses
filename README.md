# Treses

Un juego de puzle web inspirado en la mecánica de Threes!: desliza las fichas, junta 1 + 2 para hacer 3 y después combina parejas iguales (3 + 3, 6 + 6, 12 + 12…) para llegar lo más lejos posible.

## Jugar

Abre https://instinct-q0jwr3.github.io/treses/ desde el móvil o el ordenador.

- **Móvil**: desliza en cualquier dirección sobre el tablero.
- **Ordenador**: flechas del teclado o arrastra con el ratón.
- La partida y el récord se guardan solos en el navegador.

## Reglas

- En cada deslizamiento, todas las fichas se mueven una casilla en esa dirección.
- Un **1** y un **2** que se juntan forman un **3**. A partir de ahí solo se combinan parejas iguales.
- Tras cada movimiento aparece una ficha nueva por el lado contrario (la ves en «Siguiente»).
- Puntuación: 3 vale 3 puntos, 6 vale 9, 12 vale 27… cada doble triplica.

Sin cuentas, sin anuncios, sin conexión necesaria tras la primera carga.
