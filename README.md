# 2048

El 2048 clásico: desliza las fichas y junta dos iguales para sumarlas hasta llegar a 2048.

Juega en https://instinct-q0jwr3.github.io/treses/

- En móvil, desliza en cualquier dirección sobre el tablero.
- En ordenador, usa las flechas o arrastra con el ratón.
- Tras cada movimiento aparece un 2 o, a veces, un 4. Si el tablero se llena sin movimientos posibles, la partida termina.
